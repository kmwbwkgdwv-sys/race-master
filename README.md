# 🦎 ぬりかくれ！（ペイントかくれんぼ）

体をペイントして風景に溶け込む、ブラウザで遊べるオンラインかくれんぼゲームです。
Three.js（描画）＋ Firebase Realtime Database（通信）だけで動き、ビルド不要で GitHub Pages にそのまま公開できます。

## 遊び方

1. プレイヤー名を入力してスタート
2. ルームIDを入力して参加（同じIDの人と同じ部屋に。最大12人。無ければ新規作成）
3. 入るとすぐ「ロビー」に出ます。自由に歩き回ったり、体を塗ったり、くっつく練習をしながら参加者を待てます
4. ホスト（👑）が「🏠 ルーム設定」でマップ・モード・時間などを決めて「▶ ゲーム開始」を押すと **10秒のカウントダウン**
5. ロビーのまんなかの **HUNTER の円** に乗っていると鬼になれます（乗っている人が多ければその中からランダム、だれも乗っていなければ全員からランダム）。円の中に体の中心が入っていれば「🔴 HUNTER の円に乗っています」と表示され、0 になった瞬間の状態で決まります
6. 隠れる時間のあいだ、鬼はだれもいないロビーで待ちます（歩き回れます）。時間が来るとゲームのマップへ

**マップ（10種類＋ランダム）** おうち / 公園 / 学校 / 倉庫 / 夜の商店街 / ガソリンスタンド / サーキット / 古代の砂漠 / ネオン街 / 火山
（後半5つは「まんたんステーション」「レースマスター」の風景・オブジェを丸みのある形で作り直したもの。`tex/` の床テクスチャも「まんたんステーション」のものです）

**キャラ** まっ白な体を自分で塗ります。頭・胴・手足をなめらかにつないだ1つの形で、腕や脚のつけ根も体になじんだまま曲がります（つなぎ目や凸凹なし）。色は体の表面に直接塗るので、ポーズを変えても塗った場所はそのまま。隠れる側は鬼より小さく、「丸キャラ／四角キャラ」と大きさ（1倍・1.5倍・2倍）を「体・ポーズ調整」で選べます。

**ポーズ** 右下の「ポーズ」ボタンを押すと、画面の真ん中に丸い枠が出ます。中の絵（20種類）を押すとそのポーズになります。ポーズは用意されたものだけで、自分では作れません（PC は O で枠、Q で次のポーズ）。「🧍 体の形」では丸／四角・大きさ・体の向きだけを変えられます。

**マップの大きさ** どのマップも物ごと1.5倍の大きさです（キャラが小さく、家具や街が大きく見えるので隠れやすい）。机の下にもぐれます。

**街（夜の商店街・ネオン街）** 大通りと横道、噴水広場、中庭、路地のある街です。建物は外壁ぜんたいが模様（レンガ・しま・水玉・市松など）で、日よけやベランダ（乗れる）、横に突き出た看板（両面にくっつける）、雨どい、壁画、屋上の低い壁・タンク・大きな看板があります。ネオン街は模様そのものが光ります。

**カメレオンのように隠れる場所** 「同じ色・模様の場所にはりついて、体をその色に塗る」ための場所をどのマップにもたくさん置いています。
- くぼみのある模様の壁：体が入る深さのくぼみ（高い所のくぼみもある）。くぼみの奥は無地なので、その色に塗れば溶け込める
- 地層の岩：色の帯が重なった大きな岩。下の層が小さく、上の層がひさしになっていて、その下に立って隠れられる（岩の帯と同じしまを体に塗る）
- 岩のすき間：2つの大きな岩のあいだにもぐれる（上に石がはさまって屋根になっていることも）
- 角ばった岩：平らな面が多く、大きな色の面の岩肌なので、面に体を寄せて同じ色に塗れる
- もようの大きなブロックの山：ブロックのすき間や、上にのったブロックの下のトンネルに入る
- しましまの階段（階段の下にもぐれる）・らくがきの壁（しぶきの色を塗る）・床の大きなもよう（寝そべって同じもように塗る）
- ほかに模様の壁（コの字のくぼみ）・しましまの丸い柱・きのこ・模様のマット・にじのアーチ・花のおか・絵がかかった壁など

**遊具** 公園の遊具の広場には、すべり台（踊り場の下にもぐれる・すべる所は歩いてものぼれる）・ジャングルジム（中にもぐれる・上に乗れる・中に模様の板）・ブランコ・シーソー・どうぶつのスプリング遊具・砂場（砂山・お城・バケツ。寝そべって砂の色に）・半分うまったタイヤのトンネル・ボルダリングの壁（下にマット）・回転ジャングル・鉄棒・ままごとハウス（中に入れる）・トランポリン（下にもぐれる）があります。サーキットや家の子ども部屋、学校の体育館にも置いています。

**いろいろな形の道具・家の中の物** ぬいぐるみの山（くまの間にまぎれる）・こたつ（ふとん・みかん・ざぶとん）・コートかけと長いコート（うしろに隠れる）・ビーズクッション・脚立・そうじ道具（そうじ機・バケツとモップ・ほうき）・自転車・庭の道具（一輪車・じょうろ・植木ばち・ホース）・楽器（ドラムセット・ギター・アンプ）・勉強づくえ（電気スタンド・地球儀・ランドセル）・おもちゃ箱・かさ立て・跳び箱とマットと平均台・イーゼルの大きな絵（体の前の方を入れて絵と同じ色に）。家はリビング・キッチン・寝室・子ども部屋・物置ごとに家具や道具をそろえ、学校は体育館・図工室・教室にそろえています。

**人形・家具（部屋の中）** ひな人形のだん・ドレスの人形とくまと人形の家・大きなロボット・きょうりゅう・ドレッサー（鏡・いす）・ダイニングセット・冷蔵庫・洗たく機・テレビ台・フロアライト・柱時計・水そう・パソコンづくえ・背の高い観葉植物などを、家・学校・ロビーの部屋ごとに置いています。

**外の小物** フェンス（金あみ・木のさく・ブロックべい）・とめてある車（いろいろな色）・並んだ自動販売機とゴミ箱・ゴミ置き場・自転車おき場・電柱・標識・カーブミラー・工事のバリケード・積んだ木箱・台車・ガスボンベ・立て看板・街灯とベンチのセットなどを、公園・街・駅・サーキット・倉庫・砂漠・火山の道ぞいにたくさん置いています。

**銅像** 台の上に、手をあげる人・考える人・胸像・動物の像があります（ブロンズ・石・大理石）。となりに何ものっていない台があることもあり、台に乗って像と同じ色に塗ってポーズすれば銅像のふりができます。公園の広場には2体の銅像と空いた台があります。

**窓のくぼみ** 街の建物の窓は、窓わく（窓台・横の柱・上のわく）が壁から出ていて、窓ガラスが奥に引っこんでいます（カーテンの模様の窓も）。くぼみに体を寄せて隠れられます。入口の両がわにもかべがあります。おうちマップの外がわの壁にも、景色の絵・窓わく・カーテンの窓をつけました。

**おうち（部屋の多い家）** 中ろうかをはさんで19の部屋があります。北：リビング（テレビとソファ・本だな・ピアノ・水そう）／和室（たたみ・おしいれ（下の段に入れる）・床の間・こたつ・びょうぶ・しょうじ）／階段ホール（階段の下にもぐれる・上のおどり場に登れる）／ダイニングキッチン（流し台・コンロ・アイランド・食卓）／パントリー（たな）／書斎／納戸／玄関（土間・上がりかまち・くつ箱）。南：主寝室（ウォークインクローゼット・ベビールームつき）／子ども部屋×2（ひな人形・2段ベッド）／遊び部屋（すべり台・ボールプール・ままごとハウス）／洗面所／浴室／トイレ／物置／趣味の部屋（卓球台・楽器・ランニングマシン・サンドバッグ）。部屋ごとに床・壁紙を変え、家具は壁ぞいに向きをそろえて置いています。内壁は外壁と同じ高さで、上には見えない天井があるので、壁を登ってもふちの上には乗れません（学校も同じ）。開いたドアのうしろ（ドアと壁のあいだ）、ソファのうしろ、服のうしろ、階段の下などに隠れられます。散らかりすぎないよう、ばらばらに置く小物はなくしました。

**学校（部屋の多い校舎）** 中ろうか（ロッカー・ベンチ・けいじ）をはさんで14の部屋があります。北：教室×2（黒板・教壇・つくえ25こ・ランドセルのたな・ロッカー）／職員室（先生のつくえの島・コピー機）／校長室（大きなつくえ・ソファのセット・旗）／保健室（カーテンで仕切ったベッド・薬のたな・身長計）／放送室（ミキサー・スピーカー）／図書室（本だなの列・読書テーブル・絵本コーナー）／昇降口（げた箱の列・ガラスの戸）。南：音楽室（ひな段・譜面台・ピアノ・ドラム・ティンパニ）／図工室／理科室（実験台）／トイレ（ドアの開いた個室）／体育倉庫（マット・とび箱・ボールかご）／体育館（バスケットゴール・観客席・幕のあるステージ。幕のうしろに隠れられる）。

**いろいろな屋根** 街の建物は、平らな屋上（タンク・看板）／切妻（えんとつ）／寄棟（天窓）／ドーム／三角屋根のならび／時計つきのとんがり屋根の塔／給水塔 のどれかになります。屋根は段になった当たり判定なので、屋根の上を歩いて登れます。公園のトイレの建物にも屋根をつけました。

**大きな家（公園）** 公園のはしに、中に入れる大きな家（16×11）があります。外かべは横板、中はかべ紙の二重のかべで、窓はガラス（外から中が見える）・よろい戸・中のカーテンつき。玄関（ポーチ・ひさし・開いたドア）と勝手口から入れます。中は7つの部屋：リビング（テレビ・ソファ・くつ箱）／ダイニングキッチン（流し台とコンロ・冷蔵庫・食卓・食器だな）／子ども部屋（2段ベッド・つくえ・おもちゃ箱）／寝室（ベッド・ナイトテーブル・入れる洋服だんす）／洗面所（勝手口・洗たく機・洗面台）／トイレ／浴室（お湯に体の下の方が沈む）。家具は壁ぞいに向きをそろえて置き、ドアの前はあけてあります。屋上にはソーラーパネルとえんとつ、庭には花だん・車・自転車・ポスト。

**作り込んだ小物** 実物をまねて細かく作っています：板とわくの木箱・ガムテープの段ボール・たが付きの木のたる・輪のあるドラム缶・クッションが分かれたソファ・背もたれと脚のいす・幕板と脚のテーブル・まくらと掛けぶとんのベッド（下にすき間）・窓とミラーとバンパーの車（下にすき間）・飲み物が並んだ自動販売機・通気口のロッカー・本だな・板のすき間のパレット・ベンチ・消火栓・ポスト・ゴミ箱・根もとが広がった木（根・枝・葉っぱのかたまり）・節のあるヤシ・うでのあるサボテン・六角の結晶など。マップにマネキン（キャラに似た物）は置きません。

**木** 幹が太く、登れます（根もとには根）。葉っぱはいくつものかたまりを集めた形で、かたいので中にはもぐれません（葉っぱの中に全身が隠れることはありません）。幹を登ると葉っぱのかたまりの外側に回り、さらに登ると葉っぱの上に立てます。上に乗ると、でこぼこの表面に体の下の方が少しだけ沈みます。しげみ・生け垣・植木・草のかたまり・落ち葉の山も同じで、表面に少し沈むだけです。

**絵・模様の壁に少しだけ体を入れる** 額縁の絵・壁紙の壁・模様の壁・街の建物の外壁・壁画・ポスター・看板などに体を押しつけると、体の前の方だけが少し入ります（全身はうまりません）。絵と同じ色や形を体に上手に塗れば同化できます（スポイトで絵の色も吸えます）。くっつき（ジャンプ長押し）で高い所の壁にも寄せられます。入るのは隠れる側だけです。

**中に入れる物** 現実で中に入れる物は中に入れます：入口のある小屋（屋根にも登れる）・横だおしの大きな段ボール・扉の開いた洋服だんす（服は奥にかかっていて、手前に立てる）・テント・半分カーテンをしめた電話ボックス／写真ブース・土管と中がからっぽの丸太（通りぬけられる）・ふたの開いた大きなゴミ箱（上から飛びこむ）・積んだタイヤのまん中の穴。

**少し沈める場所** ボールプール・湯ぶね・ゴミ箱の中に上から入ると、体の下の方だけが沈みます（沈むのは体の高さの3割ほどまで。寝そべっても全身はうまりません）。ボール・水は弾がすり抜けます。

**当たり判定** 見た目どおりの形です。丸い物は丸く、円柱は円柱、岩は岩の形（多角形）、丘は坂として歩けます。かたむいた箱・横にねかせた丸太やたる・枝・玉・タイヤ・車輪・葉っぱ・カーテン・服・パラソル・ふたなども、見た目どおりに当たります（見た目だけで当たらない物に体がうまることはありません）。下から天井に頭をぶつけても壁の向こうへ抜けません。

**模様が2重にチラつく所をなくす** 同じ平面に2つの物の面が重なると、模様がまざってチラつきます。マップを読みこむときに重なりを自動で探し、小さい方の面を少し（約2cm）だけ外へ出して直します（見た目だけ。当たり判定はそのまま）。

**スマホ** 横画面専用です（縦にすると「横向きにしてください」と表示）。ノッチ／Dynamic Island を避けて配置します。最初から、ほかのアプリの音楽を止めずにゲームの音（効果音）を重ねて鳴らします（iPhone は消音スイッチをオフに）。消音スイッチがオンでも鳴らしたいときは、設定の「音の出し方」で「マナーモードでも鳴らす」に（このときは音楽アプリが止まります）。

**鬼の画面を見る（隠れている人）** 増え鬼でもベーシックでも、隠れている人はいつでも鬼の目線を見られます。ただし動いている間はダメで、止まってから2秒たつと右下の「👀 鬼を見る」ボタン（ポーズボタンの上。ほかのボタンと重ならない場所）が押せるようになります（PC は V）。止まっている時間がボタンの輪にたまります。見ている間は体はその場で止まったまま（壁にくっついていても落ちない）。もう一度押すと次の鬼→自分の画面へ。自分の体が鬼からどう見えているか確かめられます。増え鬼では、鬼の画面でもほかの隠れている人は映りません。

**見つかったあと**
- 自分が見つかった場所に、赤い光の柱と「✖ あなたが見つかった場所」が出ます（壁ごしにも見える。自分だけ）
- 増え鬼：鬼になります。「👀 ほかの鬼を観戦」で鬼の目線を見られますが、隠れている味方の場所・名前は分かりません
- ベーシック：👻 ゴーストになって、その場で復活します。体はすけていて、鬼にも隠れている人にも見えません。歩いたり登ったりして、みんなの隠れ場所を見に行けます（左上の「見に行く」でその人のそばへ。隠れている人の名前は壁ごしに見えます）。「👀 観戦きりかえ」（PC は V）で鬼 → 隠れている人 → ゴーストで自由に、と誰でも観戦できます

**生き残りの隠れ場所が光る** 時間いっぱい隠れて見つからなかった（カメレオンの勝ち）とき、答え合わせの最初の30秒間、生き残った人の隠れていた場所に体が出て、壁ごしに赤く光り、名前も見えます。

**見逃しランキング** 鬼の視界に入っているのに見つからなかった時間だけ、隠れている人にポイントが入ります（近いほど高得点、壁の陰は対象外）。隠れる側には常に最新、鬼側には30秒に1度だけ更新されます。

**笛** 設定した間隔（30〜120秒／オフ）で隠れている人から笛が鳴ります。聞こえるのは約34m以内だけ。音を消していても、鳴った方向の画面端が光ります（前＝上、後ろ＝下）。

**不正な隠れ場所の対策** マップ外には出られず、外壁は厚く、体のパーツが壁や家具にめり込むと外へ押し出されます。内壁は家具から登れない高さです。

**ダッシュ** スティックを輪の外までぐっとたおす（PC は Shift）と、約1秒かけてだんだん速くなります（最大1.6倍）。速くなるほど視野が広がり、カメラが少しうしろへ下がり、画面のはしに速さの線が出て、「シュッ」と音が鳴ります。スティックのまわりの輪（PC は下のバー）がスタミナで、4.5秒走ると切れて歩きにもどり、3割たまるまでダッシュできません。ダッシュしている隠れる人の足音は、鬼に大きく聞こえます。

**ジャンプと壁くっつき**（隠れる側も鬼も）
- ジャンプボタン（PC は Space）を押すとジャンプ
- 壁や物のそばでジャンプを長押しすると、壁にくっついて上に登る
- 一度くっつけば、ボタンを離してもくっついたまま（スティック／WASD で上下左右に移動。てっぺんまで行くと上に乗る）
- くっついている間にもう一度ジャンプを押すと離れる（ボタンが「はなれる」に変わります）
- 外壁だけは登れません

**足音** 鬼には、動いている隠れる人の足音が聞こえます（約22m以内。近いほど大きく、来る方向から聞こえます）。じっとしていれば音は出ません。

**鬼のショットガン** 弾の広がりは小さめ（ねらったところに当たる）。弾が体にかすっただけでも見つかります（一発）。撃つと大きな銃声（ドンという音・こだま・ポンプの音）が鳴ります。ほかの鬼の銃声は、遠いほど小さく、撃った方向から聞こえます。
- 隠れる人を見つけると、**撃った人の弾だけ**全回復します（ほかの鬼の弾は増えません。分身を撃っても回復しません）
- 弾が0になった鬼は負けです（脱落して観戦にまわる）。鬼がひとりもいなくなったらカメレオンの勝ち（鬼が1人なら、弾が0になった時点で鬼の負け）

**操作** PC: WASD 移動（Shift を押しながらでダッシュ） / マウス 視点 / クリック 射撃 / Space ジャンプ（長押しで壁にくっつく） / P ペイント / O ポーズの丸い枠 / Q 次のポーズ / F 分身 / V 観戦の切り替え（隠れている人は止まって2秒で鬼の画面） / ホイール カメラ距離（右下のジャンプ・ポーズ・鬼を見るボタンもクリックで使えます）
スマホ: 左スティック 移動（輪の外までぐっとたおすとダッシュ） / 画面ドラッグ 視点 / 右下のジャンプ・ポーズ・鬼を見るボタン（スティックで歩きながら・視点を動かしながらでも、どのボタンも押せます）
PC: マウスが画面に入っている間（視点を動かせる間）はボタンを押せません。上に「Esc でマウスを出してね」と出ます

**設定** 軽量化モード・視点感度・BGM音量・効果音音量・マナーモードでも音を出す（iPhone）・ボタンの配置と大きさ（端末に保存）
- 「🕹 ボタンの配置・大きさを変える」：スティック・ジャンプ・ポーズ・撃つ・鬼を見る・道具の列・メニューの列を、ドラッグで好きな場所へ動かし、選んで大きさ（0.6〜1.8倍）を変えられます。「これを元に戻す」「全部元に戻す」も。画面の大きさに対する割合で覚えるので、横幅のちがう端末でもずれにくい
- 「音の出し方」
  - 音楽アプリといっしょに（効果音だけ）［最初はこれ］：Spotify・ミュージックなどの音楽を止めずに、銃声・足音・笛などのゲームの音が重なって聞こえます。ゲームのBGMは鳴らしません
  - 音楽アプリといっしょに（BGMも）：上と同じで、ゲームのBGMも鳴らします（BGM音量を上げると自動でこれになります）
  - マナーモードでも鳴らす：消音スイッチがオンでも鳴りますが、ほかのアプリの音楽は止まります
  - iPhone は、ブラウザのゲームだと「音楽と重ねる」と「消音スイッチがオンでも鳴らす」を同時にはできません（iOS のきまり）。音楽といっしょに遊ぶときは、本体の横の消音スイッチをオフ（着信音が鳴る状態）にしてください

「ひとりで練習」は Firebase の設定なしで動きます（役割切替ボタンで鬼も試せます）。始める前にマップを写真つきで選べて、練習中も「🗺 マップ」で変えられます。ルームのマップ選びも同じ写真つきの画面です（写真はその場でマップを撮影して作ります）。

## セットアップ

### 1. Firebase

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成
2. **Authentication → Sign-in method → 匿名** を有効にする
3. **Realtime Database** を作成（ロックモードで OK）
4. **プロジェクトの設定 → マイアプリ → ウェブアプリを追加** し、表示された設定値を `firebase-config.js` に貼り付ける（`databaseURL` を忘れずに）
5. ルールを公開する（どちらか）※ **更新したら毎回もう一度公開してください**（今回「弾切れで脱落（out）」「終わった理由（why）」が増えたので、古いルールのままでも遊べますが、新しいルールの公開をおすすめします）
   - コンソール: Realtime Database → **ルール** タブに `database.rules.json` の中身を貼り付けて「公開」
   - CLI: `npm i -g firebase-tools && firebase login && firebase use --add && firebase deploy --only database`
6. GitHub Pages で公開する場合: Authentication → 設定 → **承認済みドメイン** に `ユーザー名.github.io` を追加

### 2. GitHub Pages

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード（push）
2. リポジトリの **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後 `https://ユーザー名.github.io/リポジトリ名/` で遊べます

```bash
git init && git add . && git commit -m "ぬりかくれ！" && git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

## ルールで守っていること / 割り切り

- ログイン（匿名認証）した人だけが読み書きできる
- 1ルームの席は 0〜11 の12個だけ。席を取った人しかプレイヤー登録できない（13人目は入れない）
- 自分のプレイヤー情報・位置・スキン・分身は本人（とホスト）しか書けない
- 「見つけた」判定と分身の破壊だけは、同じルームの参加者なら書ける

サーバーを持たない構成のため、命中判定は撃った人の端末で行っています。また「増え鬼で他の隠れ場所が見えない」は画面に表示しないことで実現しており、通信内容を覗く改造までは防げません。友達同士で遊ぶ前提の作りです。
