# race-master UIレイアウト構成案（スマホ横画面固定）

## 0. 共通ルール

| 項目 | 方針 |
|---|---|
| 画面向き | Landscape Left / Right のみ許可（`GameModeManager.Awake` で固定） |
| 基準解像度 | 1920×1080、Canvas Scaler = Scale With Screen Size / Match 0.5 |
| セーフエリア | 全画面のルートに SafeArea パネルを置き、ノッチ・ホームバーを回避 |
| 親指の可動域 | 左右下隅から半径 約38%（画面高さ比）以内に操作ボタンを収める |
| 最小タッチサイズ | 96px（1080p基準）以上。主要ボタンは 180px 以上 |
| 中央エリア | 画面中央 50% は走行視界として常に空ける（HUDは四隅と上端のみ） |

│                                                                      │

### 左親指（ステアリング専用）
- **ステアリング**：◀ ▶ の2ボタン、またはスライドパッド（設定で切替）。
  アンカーは左下、幅は画面の約 28%。押下位置に応じて -1〜+1 のアナログ値を返す。
- 左手は舵取りだけに専念させ、誤操作を防ぐ。

### 右親指（速度・アクション）
| ボタン | 位置 | サイズ | 備考 |
|---|---|---|---|
| ACCEL | 右下隅 | 最大（220px） | 押しっぱなし。設定で「オートアクセル」可 |
| BRAKE | ACCELの左 | 中（150px） | 停止後も押し続けるとバック |
| DRIFT | ACCELの上 | 大（180px） | 長押し。ACCELから親指をずらして同時押しできる距離に置く |
| ITEM | DRIFTの左上 | 中（150px） | アイコン表示兼用。タイムアタック時は**非表示** |

- ACCEL と DRIFT は親指の腹で同時押しできるよう、中心間距離を 200px 以内にする。
- ドリフト中は DRIFT ボタンの縁がミニターボ段階色（青 → 黄 → 紫）で光る。

### 上端HUD
- 左上：順位（VSのみ）、ラップ数、自己ベスト
- 中央上：現在ラップタイム（タイムアタックでは大きく表示、区間差分を ±表示）
- 右上：ミニマップ、ポーズ

### モードによる出し分け
| 要素 | タイムアタック | グランプリ / VS |
|---|---|---|
| ITEMボタン・アイテム枠 | 非表示 | 表示 |
| 順位表示 | 非表示 | 表示 |
| ゴースト差分タイム | 表示 | 非表示 |
| エナジー・チップ枚数 | 非表示 | 表示（ITEM枠の下） |

出し分けは `GameModeManager.OnModeChanged` を HUD が購読し、`Rules.itemsEnabled` などを見て切り替える。

### 【更新】操作方式の刷新（追加仕様 5）
固定の ◀ ▶ ボタンは廃止し、以下に置き換える（実装：`TouchDriveInput.cs`）。
- **どこでもステアリング**：画面左半分（設定で全画面も可）のどこを触っても、その点が仮想センター。左右にずらした量がそのまま舵角になる。触れている間だけ、センターと指位置に半透明のパッドを表示する。
- **ドリフト**：右下の専用ボタンを長押し。旋回中に押し続けるとドリフトになり、ボタンの縁とタイヤの火花が 青 → 黄 → 紫 と変化、離すとミニターボ。
- **アクセル**：既定は自動（右親指をドリフトに専念させる）。設定で手動ボタンに切替可。
- ボタンの位置とサイズは設定の「レイアウトカスタマイズ」でドラッグして変更し、`ControlLayout` に保存する。
- 画面左上に自分のアイコンを置き、タップでプロフィール（名前・アイコン）変更を開く。

- 左 38%：参加者リスト。右 62%：アイテム図鑑（4列×2行、全8種が**スクロールなしで一覧**できる）。

- ［レース開始］はホストのみ表示。

## 4. ランキング画面

```
┌──────────────────────────────────────────────────────────────────────┐
│ [←]  最速ラップランキング                                            │
│ [マスター][ネオン][砂漠][ボルケーノ][コスモ]   ← ステージ切替タブ    │
├──────────────────────────────────────────────────────────────────────┤
│  順位   ユーザーID            タイム        更新日                   │
│   1     speed_king            0:38.412      11/10                    │
│   2     drift_neko            0:38.977      11/09                    │
│   …    （縦スクロール、上位100件）                                   │
├──────────────────────────────────────────────────────────────────────┤
│  あなた: 12位    my_user_id   0:42.310          （常時下端に固定）   │
└──────────────────────────────────────────────────────────────────────┘
```
- 画面表示中は `RankingService.Subscribe(stageId)` で Firebase の変更をリアルタイム購読し、順位が入れ替わった行はアニメーションで移動させる。
- 自分が上位100件に入っていない場合、下端の行は「圏外」＋自己ベストを表示する。
- オフライン時は Firebase SDK のローカルキャッシュを「オフライン表示」ラベル付きで出す。

## 5. 画面遷移と GamePhase の対応

| GamePhase | 表示画面 |
|---|---|
| Menu | メインメニュー／ガレージ／ランキング |
| Lobby | ロビー（VSのみ） |
| Loading | ステージ読み込み |
| Countdown | レースHUD＋3・2・1 |
| Racing | レースHUD |
| Results | リザルト（タイムアタックは自己ベスト比較と世界順位） |
